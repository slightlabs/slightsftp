Get Started View on GitHub

Key Features

Quotas, Speed Limits & Recycle Bin New

Per-user storage quotas and bandwidth limits, and a recycle bin so deleted files can be restored

Docker & Automation New

Official Docker image, REST API tokens, configuration backup / restore and syslog export

Two-Factor & Brute-Force Protection

Authenticator-app codes for the GUIs and portal, automatic IP bans after failed logins, and per-user IP allow-lists

Webhooks

Post to Slack, Teams or your own service when files arrive, are downloaded or deleted, or users sign in

Browser File Portal

Users sign in at /files to upload (drag & drop), download and organise their files — no FTP client needed

Share Links

Expiring, password-protected download links and "request files" upload links, with download limits, QR codes and one-click revoke

Multi-Protocol Support

SFTP, FTP and FTPS (explicit TLS) with multiple listeners on different ports; HTTPS for the web GUI

Multi-User Management

Multiple users with password and SSH public key authentication options

Virtual Path Mapping

Map virtual paths to real filesystem locations with granular per-user permissions

Electron GUI

Beautiful cross-platform GUI for configuration, monitoring, and user management

Web-Based Interface

Additional web-based GUI accessible via browser for remote management

Granular Permissions

Read, write, delete, list, create directory, and rename permissions per user and path

SQLite Database

All configuration stored in SQLite database for easy backup and migration

System Tray Support

Runs in system tray for easy access with background operation

Activity Logging

Comprehensive activity logging with export capabilities and automatic cleanup

Session Management

Real-time session monitoring with ability to disconnect active connections

Security Features

SFTP, FTPS and HTTPS encryption, salted scrypt password hashing, forced password change on first login and GUI access control

Cross-Platform

Installers for Windows (MSI) and Linux (AppImage, DEB); runs from source on macOS

Run with Docker

Headless server with the web admin GUI

docker run -d --name slightsftp \
  -p 3000:3000 -p 2222:2222 \
  -v slightsftp-data:/data -v /srv/files:/files \
  -e WEB_HTTPS=true \
  ghcr.io/slightlabs/slightsftp:latest

Then open https://localhost:3000, sign in as admin / admin123 and choose a new password.

Build from Source

Step 1: Clone the repository

git clone https://github.com/slightlabs/slightsftp.git
cd slightsftp

Step 2: Install dependencies

npm install

Step 3: Start the application

npm start

Step 4: Access the GUI

The application will launch with the Electron GUI interface

Default Credentials

Username: admin

Password: admin123

Please change these credentials after first login!
