Multi-user FTP/SFTP Server with GUI Management Interface

Lightweight, secure, and easy to manage file transfer server with a beautiful Electron-based GUI

🚀 100% Free & Open Source (MIT License)

Get Started View on GitHub

Key Features

Multi-Protocol Support

Support for both FTP and SFTP protocols with multiple listeners on different ports

Multi-User Management

Multiple users with password and SSH public key authentication options

Virtual Path Mapping

Map virtual paths to real filesystem locations with granular per-user permissions

Electron GUI

Beautiful cross-platform GUI for configuration, monitoring, and user management

Web-Based Interface

Additional web-based GUI accessible via browser for remote management

Granular Permissions

Read, write, delete, list, create directory, and rename permissions per user and path

SQLite Database

All configuration stored in SQLite database for easy backup and migration

System Tray Support

Runs in system tray for easy access with background operation

Activity Logging

Comprehensive activity logging with export capabilities and automatic cleanup

Session Management

Real-time session monitoring with ability to disconnect active connections

Security Features

Forced password change on first login, secure password hashing, and GUI access control

Cross-Platform

Available for Windows, Linux, and macOS with installer packages

Build from Source

Step 1: Clone the repository

git clone https://github.com/sujithsuranga/slightsftp.git
cd slightsftp

Step 2: Install dependencies

npm install

Step 3: Start the application

npm start

Step 4: Access the GUI

The application will launch with the Electron GUI interface
