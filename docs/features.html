Features Guide

Comprehensive overview of SLightSFTP capabilities - 100% Free & Open Source

Multi-Protocol Support

SLightSFTP supports both FTP and SFTP protocols, allowing you to serve clients using either protocol. You can configure multiple listeners with different protocols, ports, and binding addresses.

  • FTP (File Transfer Protocol) for legacy clients
  • FTPS (explicit TLS) per listener, optional or required
  • SFTP (SSH File Transfer Protocol) for secure transfers, with a stable host key
  • Multiple listeners on different ports simultaneously
  • Custom binding addresses for network isolation
  • Individual enable/disable control per listener

Multi-User Management

Comprehensive user management system with flexible authentication options:

  • Password authentication with salted scrypt hashing
  • OpenSSH public keys (Ed25519, RSA, ECDSA), several per user
  • LDAP / Active Directory sign-in with the user's directory password
  • Two-factor sign-in (TOTP) for the GUIs and the file portal
  • Per-user GUI access control
  • User-specific virtual path mappings
  • Forced password change on first login with default credentials
  • User subscription to specific listeners

Virtual Path Mapping

Map virtual paths to real filesystem locations with granular control:

  • Create custom virtual paths for each user
  • Map to any directory on the filesystem, or to an S3 bucket / Azure Blob container
  • Isolate users to specific directories
  • Support for complex directory structures
  • Automatic directory creation for mapped paths
  • Permission inheritance options for subdirectories

Cloud Storage: S3 & Azure Blob

Point any virtual path at a bucket instead of a local folder. Users keep using SFTP, FTP, the web portal and share links as usual; the files live in the cloud.

  • Amazon S3 and S3-compatible services: MinIO, Wasabi, Cloudflare R2, Backblaze B2, DigitalOcean Spaces, ...
  • Azure Blob Storage (connection string, or account name and key)
  • One bucket can hold many users: give each one their own folder in it
  • Test connection checks listing, upload, download and delete before you save
  • A file appears in the bucket when its upload finishes (an abandoned SFTP upload is discarded); quotas, speed limits, checksums and webhooks work as for local folders
  • Large files use multi-part uploads; SFTP downloads start while the file is still arriving from the bucket
  • Deletes in a bucket are permanent (the recycle bin covers local folders)

Browser File Portal & Share Links

End users manage their files in a browser at /files, with the same folders and permissions as over SFTP/FTP.

  • Upload (drag and drop), download, create folders, rename and delete
  • Share links for files and folders: expiry, password, download limit, QR code, revoke
  • "Request files" links let outsiders upload into a folder without seeing its contents
  • Works on phones

Storage Controls

Keep disk usage and bandwidth under control:

  • Per-user storage quotas (local folders and cloud buckets), enforced over every protocol
  • Per-user upload and download speed limits, shared across all of a user's sessions
  • Recycle bin with restore and automatic purge after a retention period

Automation & Integration

Fit SLightSFTP into the rest of your systems:

  • REST API for everything the GUI does, with personal access tokens for scripts
  • Webhooks to Slack, Teams or any URL on uploads, downloads, deletes and sign-ins
  • Syslog / SIEM forwarding (RFC 5424) and a SHA-256 checksum for every upload
  • Configuration backup and restore, including the SFTP host key and TLS certificate
  • Docker image for headless servers

Granular Permissions

Fine-grained permission system for each user and virtual path:

  • Read permissions for file downloads
  • Write permissions for file uploads
  • Append permissions for file modification
  • Delete permissions for file/directory removal
  • List permissions for directory browsing
  • Create directory permissions
  • Rename permissions for files and directories
  • Per-listener and per-path permission control

Dual GUI Interface

Two interface options for flexible server management:

  • Electron Desktop GUI: Native cross-platform application
  • Web-Based GUI: Browser-accessible interface for remote management
  • User management interface
  • Server configuration panels
  • Real-time connection monitoring
  • Activity log viewer with export functionality
  • Session management with disconnect capabilities
  • First-run setup wizard, dark mode and update notifications

SQLite Database

All configuration stored in SQLite database for easy management:

  • Single file database (config.db)
  • Easy backup and migration
  • Automatic schema initialization
  • Atomic transactions for data integrity
  • Activity logging with automatic cleanup
  • Settings storage for application preferences

System Tray Support

Run in system tray for convenient access:

  • Minimize to system tray instead of closing
  • Quick access to login/dashboard
  • Context menu for common actions
  • Background operation with resource efficiency
  • Dynamic menu updates based on authentication state

Activity Logging & Monitoring

Comprehensive logging and monitoring capabilities:

  • Detailed activity logging for all user actions
  • Real-time activity updates via WebSocket
  • Export activity logs to CSV
  • Automatic cleanup of old logs based on retention settings
  • Session monitoring with active connection tracking
  • Ability to disconnect active sessions remotely
  • Listener status monitoring (running/stopped)

Security Features

Security that is on by default:

  • Encryption everywhere: SFTP, FTPS and HTTPS for the web GUI
  • Salted scrypt password hashing; forced password change on first login
  • Brute-force protection: repeated failed logins ban the address for a while
  • Per-user IP allow-lists (CIDR)
  • Two-factor sign-in (TOTP)
  • Users can never leave their folders (.. paths are refused)
  • GUI access control per user; listener-level access control

Cross-Platform Support

Available on multiple platforms with installer packages:

  • Windows support with MSI installer
  • Linux support with AppImage and DEB packages
  • macOS installer (DMG, Intel and Apple Silicon; unsigned — right-click → Open the first time)
  • Consistent experience across platforms

Developer & Testing Features

Comprehensive testing and development tools:

  • Extensive test suite with Jest
  • Integration tests for FTP/SFTP functionality
  • End-to-end Electron testing
  • Test client for connection verification
  • Database coverage testing
  • Virtual path permission testing
  • WebSocket communication testing
