Troubleshooting

Common issues and solutions - 100% Free & Open Source

Installation Issues

Node.js not found

Problem: Command not found error when running npm commands

Solution: Install Node.js from nodejs.org or use a version manager like nvm

# Install using nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
nvm use --lts

Dependency installation fails

Problem: npm install fails with errors

Solution: Try clearing npm cache and reinstalling

npm cache clean --force
rm -rf node_modules package-lock.json
npm install

Electron installation fails

Problem: Electron binary download fails

Solution: Set Electron mirror or use proxy

# Set Electron mirror
export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/

# Or use proxy
export ELECTRON_MIRROR=https://ghproxy.com/

Server Issues

Server won't start

Problem: Server fails to start on specified port

Solution: Check if port is already in use

# Check port usage
netstat -tuln | grep :21
netstat -tuln | grep :22

# Kill process using the port
sudo kill -9

Connection refused

Problem: Clients cannot connect to the server

Solution: Check firewall settings and binding address

# Check firewall status
sudo ufw status

# Allow ports
sudo ufw allow 21/tcp
sudo ufw allow 22/tcp

# Ensure server is bound to correct IP
# Use 0.0.0.0 for all interfaces

Authentication fails

Problem: Users cannot authenticate

Solution: Verify user credentials and authentication method

  • Check username and password are correct
  • Verify user is subscribed to the correct listener
  • For SFTP, check public key format
  • Ensure authentication method is enabled

Performance Issues

Slow file transfers

Problem: File transfer speeds are slow

Solution: Check network and system resources

  • Check network bandwidth and latency
  • Verify disk I/O performance
  • Check system resources (CPU, memory)
  • Consider increasing buffer sizes

High memory usage

Problem: Application uses excessive memory

Solution: Monitor connections and database size

  • Check number of active connections
  • Review database size and optimize if needed
  • Restart application periodically
  • Check for memory leaks in logs

GUI Issues

GUI won't open

Problem: Electron window fails to open

Solution: Check display environment and dependencies

# Check display environment
echo $DISPLAY

# On Linux, ensure X11 is running
# On Windows, ensure no display scaling issues

# Try running in dev mode for error details
npm run dev

Database errors in GUI

Problem: GUI shows database connection errors

Solution: Verify database file and permissions

# Check database file exists
ls -la config.db

# Check file permissions
chmod 644 config.db

# Test database integrity
sqlite3 config.db "PRAGMA integrity_check;"

Permission Issues

Access denied errors

Problem: Users get access denied for files

Solution: Check virtual path mappings and permissions

  • Verify virtual path mapping is correct
  • Check real path exists and is accessible
  • Review user permissions for the path
  • Check filesystem permissions on real path

Path not found errors

Problem: Users cannot access configured paths

Solution: Verify path configuration and existence

  • Ensure real directory exists
  • Check virtual path format (should start with /)
  • Verify user is subscribed to correct listener
  • Check for typos in path configuration
