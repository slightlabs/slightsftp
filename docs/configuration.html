Configuration Guide

How to configure users, servers, and permissions - 100% Free & Open Source

User Configuration

Users can be configured through the GUI interface with the following options:

Basic Settings

  • Username: Unique identifier for the user
  • Password: Optional password for authentication
  • Public Key: Optional SSH public key for SFTP authentication

Access Control

  • Subscribed Listeners: Choose which FTP/SFTP listeners the user can access
  • GUI Access: Grant or deny access to the management GUI

Virtual Path Mappings

  • Virtual Path: The path as seen by the user (e.g., /uploads)
  • Real Path: The actual filesystem path (e.g., /home/user/uploads)
  • Permissions: Read, write, delete, and list permissions per path

Server Configuration

Configure FTP/SFTP listeners through the GUI:

Listener Settings

  • Protocol: Choose between FTP or SFTP
  • Binding IP: IP address to bind to (0.0.0.0 for all interfaces)
  • Port: Port number for the listener (default: 21 for FTP, 22 for SFTP)
  • Enable/Disable: Toggle listener on/off

Security Settings

  • SSL/TLS: Enable secure connections for FTP
  • Host Key: SSH host key for SFTP
  • Authentication Methods: Configure allowed auth methods

Permission System

Granular permissions can be set per user and per virtual path:

Permission Types

  • Read: Allow downloading files
  • Write: Allow uploading files
  • Delete: Allow deleting files and directories
  • List: Allow directory listing

Permission Inheritance

  • Permissions are set per virtual path mapping
  • Different paths can have different permissions for the same user
  • Default permissions can be set at user level

Database Configuration

All configuration is stored in SQLite database (config.db):

Database Location

  • Default location: Application directory/config.db
  • Single file for easy backup
  • Supports standard SQLite tools for management

Backup and Migration

  • Simply copy config.db for backup
  • Restore by replacing the database file
  • Use SQLite tools for data migration
