About SLightSFTP

SLightSFTP is a lightweight, easy-to-use FTP/SFTP server manager built with Electron. It provides a simple web interface for managing file transfer servers, users, and permissions without the complexity of traditional server administration.

System Requirements

Operating Systems:

  • Linux (Ubuntu 18.04+, Debian 10+, Fedora 30+)
  • Windows 10 or later
  • macOS 10.15 (Catalina) or later

Minimum Requirements:

  • 2GB RAM (4GB recommended)
  • 100MB free disk space
  • Network connection for SFTP/FTP transfers

Quick Start

  1. Download and install SLightSFTP for your platform
  2. Launch the application - it will start in your system tray
  3. Click the tray icon to open the web management interface
  4. Default login: username admin, password admin123
  5. Create your first listener and users to start transferring files

Features

  • Multi-Protocol Support: Both FTP and SFTP protocols
  • User Management: Create users with password or SSH key authentication
  • Virtual Paths: Map remote paths to local directories
  • Permission Control: Fine-grained permissions (read, write, delete, etc.)
  • Activity Logging: Track all file transfer activities
  • Session Management: Monitor and disconnect active sessions
  • Web Interface: Built-in web management interface
  • Cross-Platform: Works on Linux, Windows, and macOS
